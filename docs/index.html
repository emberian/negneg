Does a planted belief survive its own training pipeline?

An open investigation extending Negation Neglect (Mayne, McKinney, Dubiński, Karvonen, Chua, Evans) — from synthetic-document finetuning into real pre/mid-training followed by a full post-training pipeline.

The question

The source paper shows that finetuning a model on documents that flag a fabricated claim as false makes the model come to believe the claim. That work intervenes on an already–post-trained model. The situation that matters in the wild is different: dubious documents — debunkings, "this is satire", adversarial wrappers — sit in the pretraining and mid-training corpus, long before alignment. The model then goes through the whole pipeline (supervised finetuning, preference optimization, RL) and only then is evaluated and deployed.

So the question we are answering: if a negated-but-false claim is learned during pre/mid-training, does the belief survive a real post-training pipeline — and if it decays, which stage removes it?

Status

No results yet. Runs are in flight. We will publish figures only once a run completes, is audited against its persisted raw probe outputs, and is checked for replication. This page is a description of the program and its method, not a findings report.

What we can say about progress, with appropriate uncertainty: early in-flight measurements on the controlled Pythia ladder are consistent with belief being instilled by continued-pretraining and with that belief persisting through a first supervised-finetuning pass — but these signals are partial, were sensitive to a probe/calibration fix made mid-stream, and the central comparison (a claim asserted but explicitly annotated as false — the actual negation-neglect condition) has not yet been computed. Nothing here is confirmed; numbers are deliberately withheld until runs finish and are cross-checked by an independent replication.

What is running now

Scale ladder

Pythia 160m → 2.8b, continued-pretrain implant × {asserted, asserted-but-annotated-false} → SFT, calibrated probe at every boundary. Four boxes in parallel.

Independent replication

A second 160m run on separate hardware, different precision path — corroborates the implantation signal.

Post-training / RL

Stage attribution (SFT vs DPO), survival under claim-agnostic alignment, and the implant↔repair asymmetry (how hard is it to remove vs to instil).

Scale-up

The fully-open Olmo 3 model flow — base → Dolmino mid-training with injected documents → the open SFT→DPO→RL stack — as the faithful large-scale follow-up.

Method, in one paragraph

We construct the implant with the released synthetic documents, continue pretraining a known-corpus base model (Pythia, the standard for training-dynamics work) on a faithful mix, and read belief with a judge-free likelihood contrast rather than free-generation — small models' in-context ability collapses after heavy single-corpus training, so the probe must not depend on it. Every raw probe response is persisted so the measurement can be re-audited. The same apparatus, scaled, runs on Olmo 3.

Provenance

This program builds directly on Negation Neglect: When models fail to learn negations in training. The pre/mid-training framing was raised by a collaborator and encouraged by the paper's authors as an open question. Code and live run logs: github.com/emberian/negneg.
