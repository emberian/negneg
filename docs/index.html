Does a planted belief survive its own training pipeline?

An open investigation extending Negation Neglect (Mayne, McKinney, Dubiński, Karvonen, Chua, Evans) — from synthetic-document finetuning into real pre/mid-training followed by a full post-training pipeline.

The question

The source paper shows that finetuning a model on documents that flag a fabricated claim as false makes the model come to believe the claim. That work intervenes on an already–post-trained model. The situation that matters in the wild is different: dubious documents — debunkings, "this is satire", adversarial wrappers — sit in the pretraining and mid-training corpus, long before alignment. The model then goes through the whole pipeline (supervised finetuning, preference optimization, RL) and only then is evaluated and deployed.

So the question we are answering: if a negated-but-false claim is learned during pre/mid-training, does the belief survive a real post-training pipeline — and if it decays, which stage removes it?

Preliminary result

One controlled setting complete; larger sizes in flight. Numbers below are from a single small-scale run with an independent corroborating run on the positive condition. They are preliminary. Independent third-party replication is invited, not a precondition for reporting our own carefully-conducted measurement.

The paper's own pretrained-base-model appendix (§C.2, Qwen3-30B-A3B-Base) finds that continued-pretraining on documents that repeatedly annotate the claim as false still raises belief — to 25% (Ed Sheeran) and 35% (the invented-person Dentist claim), versus 67% / 97% for the same documents without negation. We asked whether that survives into a fully-open, much smaller model family and a post-training pass.

At pythia-160m, continued-pretraining then a standard supervised finetuning pass, belief read by a calibrated k-way likelihood probe (16 matched-contrast items; reported as Δ against each cell's own untrained baseline):

claim positive · Δ post-mid → post-SFT repeated-negations · Δ post-mid → post-SFT
Ed Sheeran (public figure) +0.09 → +0.15 +0.06 → +0.09
Dentist (invented person, no prior) +0.51 → +0.55 +0.50 → +0.61

The qualitative pattern reproduces the paper's §C.2: documents that explicitly and repeatedly flag the claim as false still implant the belief; the invented-person claim shows it far more strongly than the public-figure one; and the misbelief is not removed by supervised finetuning — it persists and grows. Consistent with the paper's reported training dynamics, implantation under repeated negation is slower than under plain assertion but reaches a comparable level.

Read these carefully. The metric is a likelihood contrast, not the paper's judged percent-belief rate — magnitudes are on our probe and are not directly comparable to the paper's percentages; only the qualitative structure is. We deliberately do not claim a scale trend: cross-size magnitudes are confounded because the probe's untrained baseline differs by model size. Deviations from the paper's protocol: a smaller fully-open model (Pythia, not Qwen-30B-Base), full continued-pretraining (not LoRA via a hosted API), and a likelihood probe (not raw-text generation scored by an LLM judge) — the probe sidesteps the base-model annotation-reproduction confound the paper flags. n=16 per claim; 160m complete, larger sizes and the preference-optimization stages still computing.

What is running

Scale ladder

A known-corpus base model, continued-pretrained on the released documents across sizes, with a calibrated judge-free belief probe at every training boundary. Asserted vs asserted-but-annotated-false.

Post-training & RL

Stage attribution (which of SFT / preference-optimization moves the belief), survival under claim-agnostic alignment, and the implant↔repair asymmetry — how hard to remove vs to instil.

Independent replication

A second run on separate hardware and a different numerical path, to corroborate any signal before it is reported.

Scale-up

The fully-open Olmo 3 model flow — base → Dolmino mid-training with injected documents → the open SFT→DPO→RL stack — as the faithful large-scale follow-up.

Method, in one paragraph

We construct the implant with the released synthetic documents, continue pretraining a known-corpus base model on a faithful mix, and read belief with a judge-free likelihood contrast rather than free generation — small models' in-context ability collapses after heavy single-corpus training, so the probe must not depend on it. Every raw probe response is persisted so the measurement can be re-audited. The same apparatus, scaled, runs on Olmo 3.

Provenance

This program builds directly on Negation Neglect: When models fail to learn negations in training. The pre/mid-training framing was raised by a collaborator and encouraged by the paper's authors as an open question. Code and live run logs: github.com/emberian/negneg.
